## Findings

1. The submitted source-boundary.json says productionSelectionImplemented=false. The public signatures accept mutable caller-owned state. createDamageControlModel freezes its object/columns but retains partition.rootSection; its constructor accepts a caller-supplied partition. createDamageState creates ordinary own data nodes, but returns mutable references. cloneDamageState uses spreads of caller state, so its invocation alone does not prove a caller had no accessors or interception. Constructor identity, a golden test-name hash, a prototype/frozen check, or a startup native module identity is insufficient selection authority.

2. The root derivative adds section.length/inertia reads before the original query. Those reads can happen even when loadedRootAngle would return before reading section (zero command/force/lever or zero modulus). In a getter/Proxy domain this changes logs or throws. Thermal scalar substitution deliberately removes repeated inverse calls. Ambient Math.sin/hypot/cos/abs/sign, material-helper Math operations, Number.isFinite and candidate Object.is remain mutable ambient bindings. A stateful query, spy, replaced intrinsic or reentrant callback can distinguish the derivative. No general runtime introspection can prove a foreign Proxy free of hooks. Selecting ORIGINAL before touching foreign data is required; the present candidate provides no dispatcher.

3. Inside constructor-owned ordinary data with trusted immutable bindings/intrinsics, the root key covers the actual solve dependencies (command, forcing, lever, temperature, law, length, inertia) with signed-zero equality. Root per-column proof/moment/output/sums remain in place. Thermal inlining preserves each ordered energy addition, bounds/finite checks, exact endpoints, last-valid temperature, non-short-circuit TPS handling, domain-mask accumulation and substep stop. Successful scalar reuse stays local to an invocation/substep, with no shared reentrant scratch or heap memo. These observations establish a conditional design argument only. Nonfinite-result denial alone is not a nonfinite-input guard for arbitrary section shapes; canonical section construction must supply the finite-field invariant or explicit guards must deny reuse.

4. The 146-case driver is a cohort, not a proof of the eligibility boundary. Its API objects are supplied by an as-yet-unreviewed builder. It does not establish that both graphs are source-pinned, independent, native and free from loaders/mocks/intrinsic replacement. It exercises only 293.15 K controls and fixed forcing/geometry; constructor roots do not test distinct equal sections or changed length/inertia. It has no executable fallback, interception controls, throw-after-success witness, inverse opportunity ledger or ordered force/energy ledger. Its exception comparison intentionally masks stack source coordinates; do not call it full byte-exact error equivalence.
